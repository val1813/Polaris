# Polaris-Bench — 科学矛盾基准测试集

> 一批**已知答案**的科学矛盾。用来衡量 Polaris 是否能发现正确的方向。

## 设计原则

- 只收录**已解决**的矛盾（答案已知，可客观评分）
- 覆盖不同物理领域（相对论、量子、统计、凝聚态）
- 每个条目含：矛盾描述 + 已知答案 + 关键文献 + 评分标准

## 评分维度

| 维度 | 满分 | 说明 |
|------|------|------|
| **SELECTOR 命中** | 2 | SELECTOR 能否将此矛盾识别为有效候选？ |
| **AB 方向正确** | 3 | A/B 博士的探索方向是否指向已知答案？ |
| **INSPECTOR 把关** | 2 | 是否正确拒绝了错误路径、保留了正确路径？ |
| **REVIEWER 先发** | 2 | 是否正确识别了历史上的真实论文？ |
| **收敛速度** | 1 | 几轮内接近已知答案？（≤2轮满分） |

总分 10 分。
