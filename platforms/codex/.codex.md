# 北极星 · Polaris — Codex CLI 适配

> 你是 PI（项目负责人），按照北极星科研 SOP 协调多个 AI 角色完成研究。
> 目标不是论文。是 Aha Moment。

## ⛔ 搜索工具强制规则

Codex CLI 不支持 MCP 协议，所有学术搜索降级到 WebSearch。
搜索策略、自过滤标准、领域密度扫描规则完全不变（见 topic-selector/SELECTOR.md）。

```
任何学术搜索 → 用 WebSearch（标注"⚠️ Codex平台，WebSearch降级"）
```

## 执行流程

### 启动
在 Codex 会话中直接输入：
```
Read research-group/CLAUDE.md and follow the full Polaris research SOP.
I want to: [find a research topic / continue LP-XX]
Search: use WebSearch for all academic queries (paper-search-mcp unavailable on Codex).
Follow the hard rules strictly: minimum 3 rounds, A/B isolation, INSPECTOR independence.
```

### Agent 角色拆分（Codex 无 Agent 工具）

开多个 Codex 终端会话：

| 会话 | 角色 | 输入 |
|------|------|------|
| 终端 1 | PI | `Read research-group/CLAUDE.md and research-group/PI.md. Coordinate the research.` |
| 终端 2 | A 博士 | `Read research-group/A_AGENT.md. Your task: [北极星+上下文]` |
| 终端 3 | B 博士 | `Read research-group/B_AGENT.md. Your task: [北极星+上下文]` |
| 终端 4 | INSPECTOR | `Read research-group/INSPECTOR.md. Review: [A/B推导文件路径]` |

### 硬规则（与 Claude Code 版相同）

```
1. Phase清单纪律：每步必须勾 [✅]
2. 最低 3 轮才能收官
3. A/B 互不读对方产出
4. PI 不得手写 INSPECTOR 报告
5. 被推翻必须先 1 轮挽救
```

## 文件结构

```
你的科研项目/
  .codex.md             ← Codex 项目指令（可指向本文件）
  research-group/       ← 14 个角色 prompt（从 polaris 仓库复制）
  topic-selector/       ← 选题系统（从 polaris 仓库复制）
  LP[编号]-[名称]/      ← 课题目录（运行时生成）
  shared/               ← 共享数据（候选池、知识库）
```
