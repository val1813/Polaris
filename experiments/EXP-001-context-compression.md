# EXP-001: 上下文压缩策略对比

**日期:** 2026-06-04
**目的:** 对比每轮全量上下文 vs 每轮摘要压缩的 token 消耗和结论质量

## 配置

- 模型: DeepSeek V4
- 课题: LP27-Tlinear-NFL
- 轮次: 3轮

## 变量

| | A组（对照） | B组（实验） |
|---|---|---|
| 上下文策略 | 每轮传完整历史（R1+R2全部产出） | 每轮只传 ≤300字PI摘要 + 阻断清单 |
| R3 A博士上下文 | ~5000行（R1+R2+全部检查） | ~50行（摘要+阻断） |

## 预期

- B组 token 消耗应显著低于 A组
- B组结论质量不应明显下降（如果有，说明摘要丢失了关键信息）
