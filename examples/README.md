# 成果展示

> 放你跑过的课题。Aha Moment、踩坑记录、完整推导——都欢迎。

## 目录结构

每个课题一个文件夹：

```
examples/
  LPXX-课题名/
    README.md           ← 课题摘要（1-2段：矛盾是什么、发现了什么、教训是什么）
    Phase清单.md         ← 执行过程（已完成项带 [✅]）
    北极星队列.md         ← 优先级演变
    synthesis/           ← 最终综合（可选）
      总结.md
    highlights/          ← 亮点（可选）
      aha_moment.md      ← 那个让你半夜坐起来的发现
      dead_end.md        ← 让你撞墙的地方
```

## 提交指南

1. 按上面的目录结构创建你的课题文件夹
2. README.md 必须包含：核心矛盾、发现、教训
3. 有 Aha Moment 的把推导链放 highlights/
4. 有踩坑的把原因分析放 highlights/
5. 提 PR 即可
