# Validation — 验证闭环

> 每个课题收官前，强制输出可被独立检验的证据。不讲故事，拿证据。

## 验证协议

课题进入收官阶段时，PI 必须确保以下三项全部满足：

### 1. 推导链路可复现

```
[ ] 核心公式的每一步代数操作可被 INSPECTOR Q5 独立重演
[ ] 所有数值有来源标注（[全文核实] / [摘要级] / [印象引用]）
[ ] 关键公式必须包含：SI 单位检查 + 至少两个极限退化验证
```

### 2. 关键结论的文献锚点

```
[ ] 每个核心声张有至少 1 篇独立文献锚点（支撑或对比）
[ ] "无先发"声明必须附带：搜索词 + 搜索工具 + 搜索结果
[ ] 先发文献明确标注差异点（不能只写"相关但不相同"）
```

### 3. 可检验预测

```
[ ] 至少 1 个具体的数值预言（带单位、带误差、带可观测条件）
[ ] 或至少指定 1 个已有实验数据的 Figure/Table 可被重新分析
[ ] 或明确标注"当前阶段无可检验预测"及原因
```

## 验证报告格式

写入 `synthesis/validation_report.md`：

```markdown
# 验证报告 — [课题名]

## 推导可复现性
| 公式 | 量纲检查 | 极限退化1 | 极限退化2 | 数值来源级别 |
|------|---------|----------|----------|------------|
| F1   | ✅/❌   | ✅/❌    | ✅/❌    | [全文/摘要/印象] |

## 文献锚点
| 声张 | 支撑文献 | 验证状态 |
|------|---------|---------|
| C1   | arXiv:XXXX | ✅ 独立确认 / ⚠️ 待核实 |

## 可检验预测
[具体预测，或"当前阶段无"的原因]
```
