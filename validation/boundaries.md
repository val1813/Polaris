# Validation Boundaries — 什么能验，什么不能

> `validate.py` 不是万能验算机。它是确定性筛子——能验的绝不靠 AI，不能验的明确标注。

## 能验的（确定性，Python 直接跑）

| 检查类型 | 方法 | 示例 |
|---------|------|------|
| **量纲一致性** | `sympy` + `pint` 逐项检查 | "左边 J，右边 kg·m²/s² → ✅" |
| **极限退化** | `sympy.limit()` 代入已知极限 | "T→0 时应退回基态值 X，实际退化到 Y → ❌" |
| **量级合理性** | 数值代入 + 范围检查 | "预言电阻率 10¹² Ω·m，已知材料范围 10⁻⁸~10⁶ → 🔴" |
| **代数恒等式** | `sympy.simplify(A-B)==0` | "声称 A=B → 化简 A-B → 非零 → ❌" |
| **守恒律符合** | 对守恒量做散度/时间导数 | "声称 ∂_μ J^μ = 0 → 代入表达式 → 散度非零 → ❌" |
| **对称性检查** | 变换下表达式是否不变 | "声称时间反演不变 → t→-t 代入 → 符号翻转 → ❌" |
| **超越函数自变量** | 检查 exp/sin/log 的输入无量纲 | "sin(5 kg) → 🔴 量纲错误" |

## 不能验的（需要外部信息，标注后跳过）

| 类型 | 为什么不能验 | 替代方案 |
|------|------------|---------|
| **"这个方程描述真实世界吗？"** | 需要实验数据对比 | 指定已有实验的 Figure/Table 做比较 |
| **"这是新发现还是先发文献？"** | 需要文献数据库 | paper-search-mcp + REVIEWER 查重 |
| **"这个物理机制在自然界存在吗？"** | 需要实验检验 | 生成可检验预言 → 等实验 |
| **"凝聚态的 X 等价于高能的 Y？"** | 跨域类比，语义层面 | ARBITRATOR §1 术语对齐 |
| **"这个近似在真实材料中成立吗？"** | 需要 DFT/MC 模拟 | 标注近似条件，不作为已验证声张 |
| **"这个数学定理能用在这里吗？"** | 定理适用条件需要判断 | 标注定理的前提假设，列出未验证项 |

## 可以接入的工具（逐步覆盖"不能验"的区域）

### 已有（本机 Python 即可）

| 工具 | 覆盖什么 | 安装 |
|------|---------|------|
| **SymPy** | 符号代数、极限、微积分 | `pip install sympy` ✅ 已有 |
| **Pint** | 物理单位/量纲 | `pip install pint` ✅ 已有 |
| **NumPy/SciPy** | 数值积分、线性代数、ODE | `pip install numpy scipy` |
| **QuTiP** | 量子系统：密度矩阵、Lindblad、能谱 | `pip install qutip` |
| **EinsteinPy** | 广义相对论：度规、测地线、张量 | `pip install einsteinpy` |
| **SymEngine** | 比 SymPy 更快的符号计算 | `pip install symengine` |

### 中型（需下载数据/模型）

| 工具 | 覆盖什么 | 说明 |
|------|---------|------|
| **Wolfram Alpha API** | 通用符号+数值计算 | 免费层 2000 次/月，覆盖 SymPy 不擅长的特殊函数 |
| **Materials Project API** | 真实材料数据对比 | 晶体结构、能带、相图，可直接查"这个预言在已知材料中出现过吗" |
| **arXiv API** | 文献元数据 | 比 WebSearch 更结构化的文献检索 |
| **COD/Crystallography Open Database** | 晶体结构数据库 | 验证结构预言的合理性 |

### 重型（需 GPU/HPC，远期）

| 工具 | 覆盖什么 | 说明 |
|------|---------|------|
| **GPAW/VASP** | DFT 电子结构计算 | 需要 GPU 集群，验证材料预言 |
| **LAMMPS** | 分子动力学模拟 | 需要 GPU，验证统计力学预言 |
| **MC/量子 MC** | 多体系统数值严格解 | 需要 HPC |
| **Lean/Coq** | 数学定理形式化证明 | 极端严格，但入门门槛极高 |

## 实际流程

```
B博士产出包含公式的结论
        │
        ▼
┌─ validate.py 能验？ ─────────────────┐
│                                       │
│  能验 → 跑验证 → 阻断？→ 打回修正     │
│  不能验 → 标注"未验证" + 原因         │
│          → 指定需要什么工具/数据      │
│          → 如果有可接入工具 → 调用    │
│          → 如果没有 → 登记为"待验证"  │
│                                       │
└───────────────────────────────────────┘
        │
        ▼
   INSPECTOR Agent（复查 validate.py 漏掉的 + 语义层面）
```

## 一句话

**`validate.py` 的边界 = 纯数学/量纲/量级。** 这恰好是 AI 最容易出错的部分。AI 擅长的语义判断（"这个解释合理吗"），留给 INSPECTOR 和 REVIEWER。各做各擅长的。
