# Contrib — 社区角色

> 领域专用的 Agent 角色，由社区贡献和维护。

## 如何贡献一个新角色

1. 在 `contrib/` 下创建 `角色名.md`
2. 按下面的模板填写
3. 提 PR，附一个你用它跑过的案例

## 角色模板

```markdown
# [角色名] — [一句话描述]

> 适用领域: [凝聚态 / 高能物理 / 量子信息 / ...]
> 触发时机: [什么时候启动这个 Agent]
> 贡献者: [你的名字]

## System Prompt

你是[角色名]，[角色定位]。

你的专长:
- [专长1]
- [专长2]

工作方式:
[具体的工作流程]

禁止:
- [不该做的事]

## 使用案例

课题: [课题名]
发现: [这个角色帮助发现了什么]
```
